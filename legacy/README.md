# legacy — код v1

Модули бота, который проработал 7 апреля — 10 мая 2026 и нашёл квартиру.
В v2 каждый из них заменяется:

| Файл v1 | Чем заменён в v2 | Почему |
|---|---|---|
| `analyzer.py` | `extract/` + `core/match.py` | Модель больше не выносит вердикт: она извлекает факты, решает код. На корпусе v1 модель поставила «мамад есть» 226 раз, из них 70 текстом не подтверждаются |
| `database.py` | `db/migrations/` + `core/store.py` | `CREATE TABLE IF NOT EXISTS` не умеет менять схему; извлечённые цена и комнаты вообще не сохранялись |
| `bot.py` | `bot/` | Один `CHAT_ID` на всё приложение, пауза в глобальной переменной, критерии в промпте |
| `main.py`, `scheduler.py` | будут переписаны под мультипрофильную выдачу | |
| `reanalyze.py` | не нужен | Переоценка под новые критерии больше не требует повторного вызова модели: факты уже извлечены |

Лежит здесь как справка — в нём много выстраданных мелочей (watchdog Telethon,
цепочка прокси, ленивый FlareSolverr), которые в v2 переносятся по частям.
Удалять не нужно.
