# 0009 — на жалобу бот отвечает итогом

**Дата:** 27 сентября 2026
**Статус:** принято, реализовано в `core/feedback.py` и миграции 018

## Из чего выросло

Кнопка «данные неверны» записывала жалобу и отвечала «разберу заново» — на
этом всё. Человек не узнавал, помогло ли. Первая настоящая жалоба пришла с
вариантом «Другое» без единого слова: что не так, пришлось угадывать по базе.

## Решение

Варианты жалобы: цена, комнаты, мамад, адрес, снято / не открывается, дубль,
агент / комиссия, не подходит мне, другое.

* **Поля** (цена, комнаты, мамад, адрес) — поле разбирается заново, как раньше.
  Когда разбор прошёл, бот отвечает **беззвучно**, ответом на карточку: «было
  X, стало Y — исправил» или «перепроверил: в объявлении X» с цитатой из текста.
  Если после правки объявление перестало подходить — говорит и убирает из ленты.
  Не прошёл за час — честно говорит, что автоматически не вышло.
* **Снято** — у Komo проверяется страница (решение 0008): подтвердилось —
  убираем у всех; не подтвердилось или источник проверить нельзя — только из
  ленты пожаловавшегося.
* **Дубль** — убираем из ленты пожаловавшегося; администратору — похожие
  объявления из базы, чтобы починить склейку.
* **Агент / комиссия** — верим человеку, даже если текст молчит: про
  посредника часто узнаёшь только по телефону. Отметка общая, объявление
  перепроверяется по всем профилям — кто ищет без комиссии, его больше не
  получит.
* **Не подходит мне** — кнопки только по критериям, которые человек задал сам.
  Бот объясняет, почему объявление прошло этот критерий (чаще всего — «нет
  данных» при «подходит и без данных»), и убирает из ленты.
* **Другое** — бот просит фразу и пересылает её администратору.

Журнал — таблица `feedback`: что было в карточке в момент жалобы, на какое
сообщение отвечать, что ответили.

## Чего не делаем

Ответы администратора из чата, команду `/feedback`, сводки жалоб — обсуждали,
решили не делать.
